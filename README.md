# 🔧 Omega PM — ระบบเตือนรอบ PM ช่างบริการ

เว็บแอปเตือนรอบเข้าบริการ PM เครื่องล้างจาน / เครื่องทำน้ำแข็ง ของโอเมก้าอีสาน (แยกออกมาจาก omega-payroll)

- **เว็บจริง:** https://omega-pm.vercel.app
- **ฐานข้อมูล:** Supabase (ตาราง `pm_stores`, `pm_records`, Storage bucket `pm-photos`) — ใช้โปรเจกต์เดียวกับ omega-payroll
- **QR ประจำร้าน:** `#store=<รหัสร้าน>` — ลูกค้าสแกนเห็นการตรวจล่าสุด ช่างใส่รหัสช่างเพื่อบันทึก PM
- **สต๊อกเครื่อง:** `#stock` (ลิงก์ตรง แชร์เข้ากลุ่มไลน์ได้) — ตาราง `stock_items`/`stock_moves` + RPC `stock_adjust` (ปรับยอด+ลงประวัติในทีเดียว กันตัดเกิน) · ตัดสต๊อกเลือกเหตุผลติดตั้ง/ขาย พร้อมชื่อร้านจากรายชื่อลูกค้า · ปุ่มคัดลอกสรุปส่งเข้าไลน์ · ลบรายการได้เฉพาะรหัสเจ้าของ
- **นำเข้าลูกค้าจากไฟล์:** ปุ่ม "📥 นำเข้าลูกค้าจากไฟล์" หน้ารายชื่อ — ลากไฟล์ Excel (.xlsx ผ่าน SheetJS CDN) หรือ CSV (รองรับทั้ง UTF-8 และโค้ดเพจไทย windows-874) ลงช่อง เดาคอลัมน์จากหัวตาราง (ชื่อร้าน/ประเภท/รุ่น/เบอร์โทร/จังหวัด/S/N/ที่อยู่/หมายเหตุ/วันติดตั้ง) ข้ามแถวที่ซ้ำกับในระบบ (ชื่อ+รุ่น หรือ S/N) แล้ว insert เป็นชุดละ 50 · วันที่รับหลายแบบ: ISO, วว/ดด/ปปปป (พ.ศ./ค.ศ.), "มีนาคม69"
- **แผนที่ลูกค้าภาคอีสาน:** `#map` (ลิงก์ตรง แชร์เข้ากลุ่มไลน์ได้) — แผนที่ SVG 20 จังหวัด (ฝังในไฟล์ สร้างจาก apisit/thailand.json) แต่ละจังหวัดโชว์จำนวนเครื่อง สีเข้มตามจำนวน · แตะจังหวัดเลื่อนไปการ์ดรายชื่อร้าน (นับร้านจากชื่อไม่ซ้ำ — ร้านที่มีหลายเครื่องแตกแถวรายเครื่อง) · แตะร้านเปิดหน้ารายละเอียดแล้วกดกลับมาแผนที่ได้
- ลิงก์เก่า `omega-payroll.vercel.app/pm.html#...` redirect มาที่นี่อัตโนมัติ (QR ที่ติดหน้าเครื่องไปแล้วใช้ได้ต่อ)
